🍔 QuickBite
B.Tech CSE Minor Project

Smart Campus Canteen Management

A 2-Tier Application built with Core Java, Swing GUI, and MySQL Database to eliminate canteen queues through pre-ordering & real-time token tracking.

📂 View Source Code on GitHub

📌 Project Summary

QuickBite bridges the gap between students and canteen kitchen staff. Students can pre-order food, track their token status live, and pick up fresh food as soon as it's ready—saving valuable break time.

Java 17+ Java Swing MySQL JDBC Multithreading

✨ Key Features

🎓 Student Pre-ordering

Multi-item cart ordering, live pricing, stock level indicators, and token generation.

👨‍🍳 Kitchen Queue & Stock

Live pending order queue auto-refreshing every 5s with default menu reset options.

🔔 Multithreading & Alerts

Asynchronous background thread flips order status to 'Ready' and rings instant ready alerts.

📊 Sales & Stock Analytics

Live stats displaying pending/ready orders along with inventory visual highlights.

How it works


1. Register with your Student ID (e.g. S101).
2. Pick multiple items in Pre-order Food and add to your Cart.
3. Place order to generate your unique Token ID.
4. Wait 40 seconds for kitchen thread alert and collect your food!
