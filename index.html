🍔 QuickBite

Smart Campus Canteen Management System built with Core Java, Swing GUI, and MySQL Database.

📌 Project Overview

QuickBite is a 2-Tier Desktop Application designed to eliminate canteen queues using pre-ordering, real-time token tracking, and automated inventory management.

Java 17+ Java Swing MySQL JDBC Multithreading

✨ Core Features

🎓 Student Portal

Pre-order food, multi-item cart management, live stock availability, and unique token generation.

👨‍🍳 Kitchen Queue

Auto-refreshing kitchen orders queue (every 5s) for staff to prepare food seamlessly.

🔔 Live Threads & Alerts

Asynchronous background thread updates status from 'Pending' to 'Ready' with instant notification popups.

📊 Stock Analytics

Custom rendered bar charts showing real-time inventory counts and out-of-stock highlights.
